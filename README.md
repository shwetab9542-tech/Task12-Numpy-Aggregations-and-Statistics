# NumPy Aggregations and Statistics

## Objective
To perform numerical analysis using NumPy aggregation and statistical functions.

## Dataset
Iris Dataset

## Tools Used
- Python
- NumPy
- Jupyter Notebook
- Scikit-learn

## Functions Used
- np.sum()
- np.mean()
- np.median()
- np.min()
- np.max()
- np.std()
- np.var()

## Analysis
Statistical functions were applied to the Iris dataset to calculate the sum, mean, median, minimum, maximum, standard deviation, and variance of different numerical features.

## Conclusion
NumPy provides efficient functions for performing numerical and statistical analysis on datasets.
